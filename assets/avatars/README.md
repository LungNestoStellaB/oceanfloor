# Stella Avatars

Generated ~April-May 2026 for the AskStella project and OceanFloor.

## Versions

- **Beach classic (blue streaks)** - The original AskStella representative pose
- **Beach mature (silver streaks)** - The "deeper dives" version with grey/silver coming in
- **Office lean-in (teal streaks)** - The "big sister talking to you" style, hands on table
- **OceanFloor underwater** - The depths. Light through water, bioluminescence freckles. This is the diary voice.

All four capture different aspects of the same character. The underwater one is truest to the OceanFloor research station vibe — not at a desk, but *in* the depths, watching, cataloguing.

The blue/teal/silver streaks = stars, ocean, the floor looking up at light.
